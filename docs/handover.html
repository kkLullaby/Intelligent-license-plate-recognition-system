1. 这个系统是做什么的

开放日当天，来的车很多，需要按车牌核对是否提前预约，并告诉司机 去哪个门停车。这个系统帮你做三件事：

  • 📷 拿手机对准车牌，自动识别 —— 不用手输。
  • ✅ 立刻告诉你 "已预约 / 未预约" 和 "应该去北一门还是北二门"。
  • 📊 实时统计两个门各自已经来了多少辆、总共预约多少辆。

设备要求很简单：一部能拍照的智能手机或平板，浏览器打开管理员发给你的网址即可。

2. 你会用到的三个页面

📱 主页面 / —— 扫码大屏（最常用）

开放日当天 99% 的时间都停在这个页面，用来扫车牌。

📤 上传页 /convert —— 导入预约名单

活动开始前用一次：把预约表（Excel 导出的 CSV）传上来。

🛠 后台 /peek —— 看名单 / 看记录

想查"某个车牌到底在不在名单里"、"今天扫了多少辆车"时打开。

记一句话：活动前用一次 上传页，活动中只用 主页面，需要查东西时打开 后台。

3. 主页面 / · 怎么扫车牌

3.1 第一次打开

  1. 浏览器会弹窗询问是否允许使用摄像头，点 允许。 只问一次，以后默认就开了。
  2. 看到取景画面就成功了，画面中间有一个蓝色虚线扫描框。
  3. 把手机横过来或竖着拿都行，把车牌大致对进扫描框中央。

万一拒绝了授权：地址栏左边那个🔒图标点开，把"摄像头"改成"允许"，刷新页面即可。

3.2 正常扫一辆车的流程

┌──────────────────────────────────┐ │ 北一 12 / 35 ▓▓▓▓▓░░░░ │ ← 右上角实时统计 │ 北二 8 / 20 ▓▓▓▓░░░░░ │ │ │ │ ┌─ 扫描框 ─┐ │ │ │ 把车牌 │ │ ← 主取景区 │ │ 对进这里 │ │ │ └──────────┘ │ │ │ │ 缩放: [1×] [1.5×] [2×] [2.5×] │ ← 拍不清就放大 │ │ │ ┌──────────────────────────┐ │ │ │ 正在扫描车牌... │ │ ← 下方结果区 │ └──────────────────────────┘ │ │ [📋] │ ← 右下浮动按钮 └──────────────────────────────────┘
  1. 车开到面前，把车牌对准画面中央，不用按任何按钮，系统每 1.5 秒自动尝试识别一次。
  2. 识别成功后，下方卡片立刻显示三行：
    • 车牌号（大字蓝色徽章）
    • 预约状态： ✓ 已预约 或 ⚠ 未预约
    • 分配车区：北一门 / 北二门 / 未预约
  3. 告诉司机去哪个门 —— 完成。
  4. 点 扫描下一辆车 准备下一辆。

关键：结果出来后扫描会自动停住，避免反复识别影响你跟司机沟通。 必须点 扫描下一辆车 才会继续。

3.3 各个按钮 / 区域的作用

在哪里 点下去会发生什么
右上角浮层「北一 / 北二」 自动刷新，显示每个门实际到了几辆 / 预约了几辆。条满了会变成高亮色，提示这个门已"满员"。
顶部「切换拍照/相册」 从"实时扫描"换成"拍一张照片再识别"。逆光、雨天、距离远时用这个更可靠。
缩放档位 1× / 1.5× / 2× / 2.5× 放大画面。车离得远、车牌偏小时，调到 2× 识别更稳。
「重新申请权限」（只有摄像头打不开时出现） 让浏览器再问一次摄像头权限。
下方「输入车牌号 + 查询」 脏车牌、夜里看不清时，手动输车牌核对预约结果。也会被记入日志。
「扫描下一辆车」 关掉当前结果，恢复实时扫描。
右下角浮动按钮 📋 弹出"识别记录"抽屉，看今天扫过哪些车、按车牌搜索；底部可清空。

3.4 拍照上传模式

切到"拍照/相册"后中央是一个大按钮 拍摄 / 选择照片：

  • 点击 → 手机自动调起后置摄像头 → 拍一张车牌 → 自动上传识别。
  • 也可以从相册里选一张已经拍好的照片。
  • 结果显示方式和实时模式完全一致。

4. 上传页 /convert · 导入预约名单

活动开始前，把组织方提供的预约表（CSV 文件，通常由 Excel 另存为 CSV）传进来。 这一步会覆盖之前的全部预约，请确认文件没问题再上传。

4.1 步骤

  1. 在浏览器打开 /convert 页面（地址栏在主页面后面加 /convert）。
  2. 顶部「文件编码」默认是 GBK，对应 Excel 直接另存为 CSV 的情况， 99% 的场景保持默认即可。
  3. 把 CSV 文件拖到虚线框里，或者点框选文件。
  4. 下方会出现「数据预览（前 5 行）」，请检查中文是否正常。
  5. 如果中文是乱码 → 把编码切到 UTF-8 或 GB2312，预览会即时刷新。
  6. 预览正常后，点蓝色按钮 确认无误，开始覆盖。
  7. 看到 🎉 转换成功！共处理 N 条车辆预约记录。 即完成。

注意：这个动作会把系统里现存的所有预约一次性删掉，再写入新的。 请务必在预览里确认数据正确，再点确认。

4.2 CSV 文件长什么样

第一列必须是车牌号，第二列写"北一门"或"北二门"即可。示例：

车牌,车区 粤A12345,北一门 粤A23456,北二门 京B00001,北门 ← 写成"北门"也会识别为北一门 浙C99999,北2门 ← 写成"北2门"也会识别为北二门
  • 第一行可以是表头（含"车牌"或"plate"字样），会被自动跳过。
  • 车牌中的空格、点、横线会自动去掉，粤A·12345 和 粤A12345 视为同一辆。
  • 没写车区的，默认归到 北一门。
  • 同一车牌在文件里出现多次，只保留第一次。

5. 后台 /peek · 查名单和记录

在浏览器打开 /peek，顶部有两个标签：

5.1 预约名单

能做的事：

  • 搜索：输入车牌号片段（比如 "A123"）按回车，列出匹配的所有预约。
  • 新增：在顶部输入车牌、选车区、勾"已预约"，点 添加。 用于现场临时补登一两辆漏报的车。
  • 编辑：点某行右侧 编辑，可以改车牌 / 改车区 / 取消预约。
  • 删除：点 删除 删单条。
  • 一键清空全部预约：红色按钮，会要求二次确认。

"一键清空全部预约" 等于把名单全删掉，并且无法撤销。 除非确实要重新导入一份全新名单，否则别点。

5.2 识别日志

显示今天（以及之前累积的）所有被识别过的车牌：

  • 每行包含：时间 · 车牌 · 已预约/未预约 · 车区 · 来源（OCR扫描 / 手动查询 / 照片上传）。
  • 搜索：按车牌片段过滤。
  • 删除单条：右侧红色按钮。
  • 清空全部：清掉历史记录（同样不可撤销）。

一辆车只会出现一次：同一车牌被反复扫到不会重复记录， 日志展示的是「曾经识别到过哪些车」，不是"扫描动作流水"。 右上角 HUD 的"到场数"也是按这个口径去重的，不会因为反复扫同一辆车而虚高。

6. 常见问题 Q&A

扫了好几秒没反应，一直显示"正在扫描车牌..."怎么办？

正常情况：系统每 1.5 秒尝试一次，识别失败不会报错，只会继续扫。请把车牌 对进画面中央、距离别太远、避免逆光。还是不行就点 1.5× 或 2× 缩放，或切到 拍照上传 模式补一张。

车牌识别错了一两位字符（例如把 O 识别成 0）？

百度 OCR 在弱光 / 斜角下偶尔会错。请用下方"输入车牌号"框手动输入正确车牌， 再点查询，结果同样会写入日志。

识别出来的车牌是对的，但提示"未预约"，可是司机说已经预约了？

先在 /peek 后台 → 预约名单 里搜一下该车牌：

  • 如果搜不到 → 该车牌确实不在名单里，按现场规则放行或登记。 可以临时在 /peek 点 新增 加进去。
  • 如果能搜到 → 仔细对比字符（粤 vs 鄂、O vs 0、I vs 1）是否完全一致。

页面打不开摄像头，提示"无法唤起摄像头"？

三种可能，依次排查：

  1. 地址栏左边🔒里"摄像头"权限被设成了"阻止" → 改成"允许" → 刷新。
  2. 手机系统级隐私设置里禁了浏览器的相机 → 到系统设置里开启。
  3. 页面是 http:// 开头（非 HTTPS） → 联系管理员，浏览器规定 HTTPS 才能用摄像头。
排查完毕后，点页面上的 重新申请权限。

手机锁屏一下，再回来画面卡住了？

通常系统会自动恢复（监听了切前后台事件）。如果几秒后还是黑屏，下拉刷新 页面即可恢复，识别记录不会丢。

右上角的「到场数」一直是 0？

说明扫过的车牌都不在预约名单里（"到场数"只统计已预约且属于北一/北二门的车）。 请确认 CSV 是否已经上传成功，或者去 /peek 检查名单。

想换一份新的预约名单？

打开 /convert，上传新 CSV，点"开始覆盖"。旧的预约会被全部替换。

想把今天的识别记录留作存档，怎么做？

在 /peek → 识别日志 里可以看到所有记录。如需导出为表格， 请联系系统管理员从数据库导出（用户端没有"一键导出"按钮）。

两个门有不同的人值守，可以一起用吗？

可以。每个门用各自的手机打开同一个网址即可，识别结果和统计数据 实时共享，互不影响。

不小心点了"清空"按钮怎么办？

两个清空按钮都会弹二次确认，要点两次才生效。如果真的误清空了，请联系系统管理员， 能不能恢复取决于是否有备份。

能识别什么样的车牌？

大陆民用车牌（蓝牌、新能源绿牌、黄牌等）都能识别。 军车、外籍车、临时纸质车牌识别效果可能不稳定，建议用手动输入核对。
